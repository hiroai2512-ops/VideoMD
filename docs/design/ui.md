# VideoMD 画面設計

2026-10-02。主要な導線だけを初期版に含める。

## メイン画面

- YouTube URL入力（1件）、モデル選択（3.8 Flash / 3.5 Flash-Lite）、保存フォルダ選択、開始ボタン。
- 動画タイトル・チャンネル・投稿日時・長さを取得後に表示する。未取得の値は捏造しない。
- 処理中は区間数と現在の状態、キャンセル操作を表示。失敗時は完了した区間を保持し再開できる。
- 出力は読みやすい整文と日本語訳。必要な見出し、関連タグ5～10個。保存完了後は実ファイル名とフォルダを開く操作を表示する。
- 月内のCloud Billing利用料金と最終更新日時、処理直後の概算を区別する。
- 1,000円ごとの到達をWindows通知とアプリ内の履歴に表示する。通知履歴は再起動後も保持する。

## 設定画面

- Google Cloudプロジェクト、接続中アカウント、モデル地域、YouTubeメタデータ取得設定、Pub/Subサブスクリプションの接続状態。
- 接続中アカウントがユーザー指定アカウントと一致することを、処理開始前に確認可能にする。トークンや秘密値を表示しない。
- 閉じる操作時は「トレイ常駐」か「完全終了」を明確にする。初期案はトレイ常駐で料金通知を継続。ログアウト・PC停止中の即時通知は保証せず、次回起動で未通知分を履歴に反映する。

## 状態とアクセシビリティ

未設定・待機・メタデータ取得・文字起こし・整形・保存・完了・失敗・キャンセルを文章で区別。色だけに依存しない。全入力にラベルを付け、キーボード操作と処理開始時のフォーカス、読めるコントラストを確保する。

取得失敗、利用できない動画、認証不一致、API拒否、割当超過、出力切れ、保存先への書込失敗を表示し、既存ファイルを壊さない。
